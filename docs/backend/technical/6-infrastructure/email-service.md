# 基础设施 - 邮件服务规范

---

## 1. 邮件服务用途

| 用途 | 场景 |
|------|------|
| 发送验证码 | 用户注册/登录时发送邮箱验证码 |

---

## 2. 配置项

### 2.1 环境变量

| 变量名 | 说明 |
|--------|------|
| `MAIL_HOST` | SMTP 服务器地址 |
| `MAIL_PORT` | SMTP 端口（默认：587） |
| `MAIL_USERNAME` | 用户名 |
| `MAIL_PASSWORD` | 密码 |
| `MAIL_FROM` | 发件人地址 |

### 2.2 Spring Boot 配置

```yaml
spring:
  mail:
    host: ${MAIL_HOST}
    port: ${MAIL_PORT}
    username: ${MAIL_USERNAME}
    password: ${MAIL_PASSWORD}
    properties:
      mail:
        smtp:
          auth: true
          starttls:
            enable: true
```

---

## 3. 邮件模板

### 3.1 验证码邮件

| 项目 | 内容 |
|------|------|
| 主题 | Your Verification Code |
| 内容 | 您的验证码是：{code}，5 分钟内有效。 |

---

## 4. 发送限制

| 限制项 | 值 | 说明 |
|--------|-----|------|
| 同一邮箱发送间隔 | 60 秒 | 防刷机制 |
| 验证码有效期 | 5 分钟 | 超过后失效 |

---

## 5. 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| SMTP 连接失败 | 记录日志，抛出异常 |
| 发送超时 | 重试 3 次 |
| 邮箱不存在 | 不返回具体错误（防邮箱枚举） |

---

## 6. 约束

| 约束 | 说明 |
|------|------|
| 敏感信息 | 邮件密码必须通过环境变量注入 |
| 错误消息 | 不向用户暴露邮件发送失败原因 |
| 日志记录 | 记录邮件发送成功/失败日志 |
