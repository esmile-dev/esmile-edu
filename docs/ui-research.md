# Vibe Coding 前端体验方法论研究

**日期**: 2026-05-03
**状态**: 研究完成

---

## 1. 核心工作流

```
PRD文档 → 设计规范 → AI生成UI → 人工微调 → 组件库固化
```

**关键技术栈**：Vue 3 + Vite + shadcn-vue + Tailwind CSS

---

## 2. 设计到代码的完整链路

### 2.1 设计阶段

| 工具 | 用途 | 特点 |
|------|------|------|
| **Figma** | 界面设计 | 原型、标注、导出 |
| **Google Stitch** | AI设计 | 自然语言生成UI |
| **Excalidraw** | 流程图 | 快速原型、头脑风暴 |

**推荐流程**：
1. PRD → 手绘流程图 (Excalidraw)
2. 流程图 → 高保真设计稿 (Figma)
3. 设计稿 → AI可理解的设计规范 (Claude Code)

### 2.2 设计规范 Prompt 模板

```markdown
你是一个UI/UX设计师。请为以下功能设计规范：

**角色**：学生/教师/管理员
**功能**：登录/注册/课程列表/兑换码/视频播放
**要求**：
- 使用shadcn-vue组件库
- Tailwind CSS样式
- 中文界面
- 响应式设计（mobile-first）

**输出**：
1. 页面结构（组件层级）
2. 状态定义（默认/加载/空/错误）
3. 交互流程
4. 视觉规范（颜色/间距/字体）
```

### 2.3 AI 生成代码流程

```
设计规范 → Vue组件 → Tailwind样式 → 响应式适配 → 测试验证
```

**关键点**：
- 提供组件的具体示例代码
- 说明状态转换的边界条件
- 指定设计 token（颜色、间距）

## 3. shadcn-vue 组件选用策略

### 3.1 MVP 核心组件

| 组件 | 用途 | 优先级 |
|------|------|--------|
| `Button` | 所有操作入口 | P0 |
| `Input` | 登录/注册/搜索 | P0 |
| `Card` | 课程卡片/课程详情 | P0 |
| `Badge` | 状态标签 | P1 |
| `Dialog` | 确认/编辑弹窗 | P1 |
| `Table` | 管理后台列表 | P1 |
| `Avatar` | 用户头像 | P2 |
| `Dropdown` | 下拉菜单 | P2 |

### 3.2 角色专属组件

**学生端**：
- `CourseCard` — 课程卡片（含封面、标题、进度）
- `VideoPlayer` — 视频播放器（含防盗链处理）
- `RedeemInput` — 兑换码输入

**教师端**：
- `CourseEditor` — 课程编辑（含章节管理）
- `VideoUploader` — 视频上传（含进度条）
- `CodeGenerator` — 兑换码生成

**管理端**：
- `DataTable` — 数据表格（含筛选、分页）
- `StatsCard` — 数据统计卡片
- `UserStatusBadge` — 用户状态标签

## 4. Vibe Coding 实践指南

### 4.1 Prompt 工程

**好 Prompt 结构**：
```
[上下文] 你是一个Vue 3开发者，使用shadcn-vue
[任务] 创建登录页面，包含邮箱和验证码输入
[约束] 移动端优先，响应式，支持中文
[示例] 参考 shadcn-vue Button 组件的用法
[验证] 运行测试确保功能正常
```

**Bad → Good 对比**：

| Bad | Good |
|-----|------|
| "做个登录页面" | "创建 src/student/views/Login.vue，包含邮箱+验证码登录，使用 shadcn-vue Input 组件，移动端优先，响应式" |
| "课程卡片要好看" | "创建 CourseCard 组件，显示封面图、标题、讲师名、时长，使用 Tailwind grid 布局，hover 有阴影效果" |

### 4.2 迭代优化循环

```
AI生成 → 人工review → 问题反馈 → AI修复 → 重复直到满意
```

**关键 review 点**：
- UI 是否与设计稿一致
- 响应式是否正常
- 交互状态是否完整
- 组件是否可复用

## 5. 三角色 UI 特点

### 5.1 学生端（学习场景）

**设计重点**：
- 视频播放为核心
- 课程列表清晰易浏览
- 兑换码输入简单

**组件选择**：
- 视频播放器（腾讯云 VOD）
- 课程卡片（带进度）
- 兑换码输入框

### 5.2 教师端（创作场景）

**设计重点**：
- 课程管理效率
- 视频上传体验
- 兑换码生成

**组件选择**：
- 富文本编辑器（课程描述）
- 文件上传（视频）
- 数据表格（兑换码列表）

### 5.3 管理端（运营场景）

**设计重点**：
- 数据可视化
- 批量操作
- 审批流程

**组件选择**：
- 统计卡片
- 数据表格（筛选/排序）
- 审批流程组件

## 8. 实施建议

### 阶段一：环境搭建（1-2天）
1. 初始化 Vue 3 + Vite 项目
2. 安装 shadcn-vue 和 Tailwind CSS
3. 配置中文环境

### 阶段二：组件库建设（3-5天）
1. 选定核心组件并定制主题
2. 建立设计 token
3. 创建角色专属组件

### 阶段三：页面开发（持续）
1. 按角色优先级开发页面
2. AI辅助生成 + 人工review
3. 组件库持续完善

## 9. Vibe Coding 核心理念

> "自然语言驱动、意图导向、持续迭代优化"

**AI生成效果 = LLM(Task + Context + Prompt)**

其中 Context（语境）在复杂项目中起到决定性作用。

**五大环节**：
1. 自然语言提示
2. AI代码生成
3. 迭代反馈
4. 代码审查
5. 部署维护

形成高频互动的 **Human-in-the-Loop** 协作循环。
