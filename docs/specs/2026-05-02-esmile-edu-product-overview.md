# esmile 教育平台 - 产品说明

**版本**: MVP v2.0
**日期**: 2026-05-03

---

## 1. 产品简介

**esmile 教育平台**是一个面向大学生的在线学习平台，连接课程老师和生源。

**核心特点**：
- 单课购买（通过兑换码）
- 视频课程学习
- 统一后台管理（教师+管理员 RBAC 权限控制）

---

## 2. 角色说明

| 角色 | 说明 | 系统归属 |
|------|------|----------|
| 学生 | 通过兑换码购买课程，观看学习 | 学生端（独立） |
| 教师 | 创建课程，生成兑换码发售 | 统一后台 |
| 管理员 | 审批教师，管理用户和课程 | 统一后台 |

**重要变更 (v2.0)**: 教师端和管理端已合并为**统一后台管理系统**，通过 RBAC 权限控制区分不同角色的功能可见性。

---

## 3. 业务流程

### 3.1 教师发售流程

```
教师注册 → 管理员审批 → 教师登录后台 → 创建课程 → 添加章节和课时 → 上传视频 → 生成兑换码
                                                                                    ↓
                                                                    闲鱼手动发货（复制兑换码）
```

### 3.2 学生购课流程

```
闲鱼下单 → 收到兑换码 → 到平台注册/登录 → 输入兑换码 → 开通课程 → 开始学习
```

### 3.3 教师审批流程

```
教师注册 → 管理员在后台审核 → 审批通过/拒绝
```

## 4. 功能说明

### 4.1 学生端

| 功能 | 说明 |
|------|------|
| 注册/登录 | 用邮箱和验证码登录 |
| 兑换课程 | 输入兑换码，开通课程学习权限 |
| 看视频 | 观看已购买课程的视频 |

### 4.2 统一后台（教师 + 管理员）

#### 权限控制说明

系统采用 **RBAC（基于角色的访问控制）**：

| 权限级别 | 说明 | 实现方式 |
|----------|------|----------|
| 菜单级 | 不同角色看到不同菜单 | 路由守卫 + 菜单过滤 |
| 按钮级 | 操作按钮根据权限显示/隐藏 | v-permission 指令 |
| API 级 | 后端接口权限校验 | Spring Security @PreAuthorize |

#### 角色权限矩阵

| 功能 | 教师 (TEACHER) | 管理员 (ADMIN) |
|------|----------------|----------------|
| 数据概览 | - | ✓ |
| 用户管理 | - | ✓ |
| 我的课程 | ✓ | ✓ |
| 全部课程 | - | ✓ |
| 课程审核 | - | ✓ |
| 我的兑换码 | ✓ | ✓ |
| 全部兑换码 | - | ✓ |
| 系统设置 | - | ✓ |

#### 教师功能

| 功能 | 说明 |
|------|------|
| 登录后台 | 用邮箱和验证码登录（需管理员审批通过） |
| 创建课程 | 设置课程标题、介绍、封面图 |
| 发布课程 | 可以先存草稿，确认后再发布 |
| 添加章节 | 课程下添加多个章节 |
| 添加课时 | 每个课时可以上传一个视频 |
| 生成兑换码 | 每次生成一个兑换码，提供给买家 |
| 管理我的课程 | 查看、编辑、删除自己创建的课程 |

#### 管理员功能

| 功能 | 说明 |
|------|------|
| 登录后台 | 用邮箱和验证码登录 |
| 数据概览 | 查看平台运营数据 |
| 用户管理 | 查看用户列表，审批教师，禁用账号 |
| 课程管理 | 查看所有课程，审核课程内容 |
| 兑换码管理 | 查看平台所有兑换码 |
| 系统设置 | 平台配置 |

### 4.3 兑换码规则

| 规则 | 说明 |
|------|------|
| 格式 | 8位字母数字，如 `A1B2C3D4` |
| 有效期 | 教师设置（如30天内必须兑换） |
| 课程权限 | 教师设置（如兑换后1年内有效） |
| 使用方式 | 一次性，兑换后失效 |
| 绑定 | 兑换后绑定到买家账号，他人无法使用 |

## 8. 统一后台登录说明

### 登录流程

1. 教师/管理员访问 `/admin/login`
2. 输入邮箱，点击发送验证码
3. 输入邮箱收到的验证码
4. 系统根据用户角色展示对应菜单

### 权限控制示例

| 用户角色 | 登录后看到的菜单 |
|----------|------------------|
| TEACHER | 个人中心、我的课程、我的兑换码 |
| ADMIN | 数据概览、用户管理、课程管理、全部兑换码、系统设置 |

## 9. 答疑

**Q: 视频安全吗？**
A: 使用腾讯云防盗链技术，可以防止视频被直接复制转发。

**Q: 兑换码能被重复使用吗？**
A: 不能，每个兑换码只能使用一次。

**Q: 课程权限会过期吗？**
A: 由教师设置，可以是永久的，也可以设置1年、半年等期限。

**Q: 教师注册后可以直接使用吗？**
A: 不可以，需要管理员审批后才能成为正式教师，审批通过后才能登录后台。

**Q: 教师和管理员是同一个系统吗？**
A: 是的，v2.0 版本已将教师端和管理端合并为统一后台管理系统，通过 RBAC 权限控制区分功能可见性。

**Q: 后期会接入闲鱼自动发货吗？**
A: 是的，计划后期接入 OpenClaw 实现自动发货。
