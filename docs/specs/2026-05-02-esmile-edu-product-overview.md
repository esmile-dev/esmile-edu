# esmile 教育平台 - 产品说明

**版本**: MVP v1.0
**日期**: 2026-05-02

---

## 1. 产品简介

**esmile 教育平台**是一个面向大学生的在线学习平台，连接课程老师和学生。

**核心特点**：
- 单课购买（通过兑换码）
- 视频课程学习
- 师生互动（作业批改 - 后期）

---

## 2. 业务流程

### 2.1 老师发货流程

```
老师创建课程 → 添加章节和课时 → 上传视频 → 生成兑换码
                                                        ↓
                                    闲鱼手动发货给买家（复制兑换码）
```

### 2.2 学生购课流程

```
闲鱼下单 → 收到兑换码 → 到平台注册/登录 → 输入兑换码 → 开通课程 → 开始学习
```

---

## 3. 功能说明

### 3.1 用户端（学生）

| 功能 | 说明 |
|------|------|
| 注册/登录 | 用邮箱和验证码登录 |
| 兑换课程 | 输入兑换码，开通课程学习权限 |
| 看视频 | 观看已购买课程的视频 |
| 试看 | 未购买的课程可以试看前几分钟 |

### 3.2 教育者端（老师）

| 功能 | 说明 |
|------|------|
| 创建课程 | 设置课程标题、介绍、封面图 |
| 发布课程 | 可以先存草稿，确认后再发布 |
| 添加章节 | 课程下添加多个章节 |
| 添加课时 | 每个课时可以上传一个视频 |
| 设置试看 | 每个视频可以设置试看时长（如免费看前3分钟） |
| 生成兑换码 | 每次生成一个兑换码，提供给买家 |

### 3.3 兑换码规则

| 规则 | 说明 |
|------|------|
| 格式 | 8位字母数字，如 `A1B2C3D4` |
| 有效期 | 老师设置（如30天内必须兑换） |
| 课程权限 | 老师设置（如兑换后1年内有效） |
| 使用方式 | 一次性，兑换后失效 |
| 绑定 | 兑换后绑定到买家账号，他人无法使用 |

## 4. 视频说明

| 项目 | 说明 |
|------|------|
| 视频托管 | 使用腾讯云视频服务 |
| 上传方式 | 在平台内直接上传，老师不需要去腾讯云操作 |
| 防盗 | 通过来源域名限制，防止视频被盗用 |
| 试看 | 设置后可免费试看前几分钟 |

## 7. 答疑

**Q: 视频安全吗？**
A: 使用腾讯云防盗链技术，可以防止视频被直接复制转发。

**Q: 兑换码能被重复使用吗？**
A: 不能，每个兑换码只能使用一次。

**Q: 课程权限会过期吗？**
A: 由老师设置，可以是永久的，也可以设置1年、半年等期限。

**Q: 后期会接入闲鱼自动发货吗？**
A: 是的，计划后期接入 OpenClaw 实现自动发货。
