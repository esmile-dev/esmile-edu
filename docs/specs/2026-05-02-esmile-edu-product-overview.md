# esmile 教育平台 - 产品说明

**版本**: MVP v1.0
**日期**: 2026-05-03

---

## 1. 产品简介

**esmile 教育平台**是一个面向大学生的在线学习平台，连接课程老师和生源。

**核心特点**：
- 单课购买（通过兑换码）
- 视频课程学习
- 师生分离，互不干扰

---

## 2. 角色说明

| 角色 | 说明 |
|------|------|
| 学生 | 通过兑换码购买课程，观看学习 |
| 教师 | 创建课程，生成兑换码发售 |
| 管理员 | 审批教师，管理用户和课程 |

---

## 3. 业务流程

### 3.1 教师发售流程

```
教师注册 → 管理员审批 → 教师创建课程 → 添加章节和课时 → 上传视频 → 生成兑换码
                                                                                    ↓
                                                                    闲鱼手动发货（复制兑换码）
```

### 3.2 学生购课流程

```
闲鱼下单 → 收到兑换码 → 到平台注册/登录 → 输入兑换码 → 开通课程 → 开始学习
```

### 3.3 教师审批流程

```
教师注册 → 管理员审核 → 审批通过/拒绝
```

## 4. 功能说明

### 4.1 学生端

| 功能 | 说明 |
|------|------|
| 注册/登录 | 用邮箱和验证码登录 |
| 兑换课程 | 输入兑换码，开通课程学习权限 |
| 看视频 | 观看已购买课程的视频 |

### 4.2 教师端

| 功能 | 说明 |
|------|------|
| 注册（待审批） | 用邮箱和验证码注册，需管理员审批通过 |
| 创建课程 | 设置课程标题、介绍、封面图 |
| 发布课程 | 可以先存草稿，确认后再发布 |
| 添加章节 | 课程下添加多个章节 |
| 添加课时 | 每个课时可以上传一个视频 |
| 生成兑换码 | 每次生成一个兑换码，提供给买家 |

### 4.3 管理端

| 功能 | 说明 |
|------|------|
| 用户管理 | 查看用户列表，审批教师，禁用账号 |
| 课程管理 | 查看所有课程，审核课程内容 |
| 数据统计 | 查看平台运营数据 |

### 4.4 兑换码规则

| 规则 | 说明 |
|------|------|
| 格式 | 8位字母数字，如 `A1B2C3D4` |
| 有效期 | 教师设置（如30天内必须兑换） |
| 课程权限 | 教师设置（如兑换后1年内有效） |
| 使用方式 | 一次性，兑换后失效 |
| 绑定 | 兑换后绑定到买家账号，他人无法使用 |

## 5. 视频说明

| 项目 | 说明 |
|------|------|
| 视频托管 | 使用腾讯云视频服务 |
| 上传方式 | 在平台内直接上传，教师不需要去腾讯云操作 |
| 防盗 | 通过来源域名限制，防止视频被盗用 |

## 8. 答疑

**Q: 视频安全吗？**
A: 使用腾讯云防盗链技术，可以防止视频被直接复制转发。

**Q: 兑换码能被重复使用吗？**
A: 不能，每个兑换码只能使用一次。

**Q: 课程权限会过期吗？**
A: 由教师设置，可以是永久的，也可以设置1年、半年等期限。

**Q: 教师注册后可以直接使用吗？**
A: 不可以，需要管理员审批后才能成为正式教师。

**Q: 后期会接入闲鱼自动发货吗？**
A: 是的，计划后期接入 OpenClaw 实现自动发货。
