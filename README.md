# esmile-edu

面向大学生的专业课程和技能培训教育平台。

## 技术栈

- **前端**: Next.js 14+ (App Router)
- **后端**: Next.js API Routes
- **数据库**: PostgreSQL + Prisma
- **视频托管**: 腾讯云 VOD

## MVP 功能

- 邮箱 + 验证码登录
- 课程管理（创建、发布、章节、课时）
- 视频上传与播放（带防盗链）
- 试看功能（按课时设置）
- 兑换码生成与兑换
